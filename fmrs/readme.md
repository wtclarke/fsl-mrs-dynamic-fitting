# Dynamic fitting of functional MRS (fMRS) data.

This section contains four sections:

1. `two_peak_simulation` replicates the theoretical findings of Tal [The future is 2D: spectral-temporal fitting of dynamic MRS data provides exponential gains in precision over conventional approaches](https://doi.org/10.1002/mrm.29456), numerically, using FSL-MRS tools.
2. `fmrs_spectrum_simulation` extends the simulations done in #1 to a full simulated 1H MRS spectrum.
3. `fmrs_demo` demonstrates the full fMRS toolset in FSL-MRS on a simulated dataset matched to reported values.
4. `fmrs_invivo_example` using the fsl-mrs dynamic fitting tools, this section replicates the results of published work performing human in vivo visual stimulation.
